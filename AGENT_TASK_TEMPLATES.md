# Minimal Task Templates

Use short requests; the repository protocol supplies the detailed rules.

Feature:
`Implement: <feature>. Follow the project development protocol. Keep scope controlled and verify regressions.`

Bug:
`Fix: <bug>. Find the root cause, add a regression check, verify affected flows, and fix task-caused failures.`

Security:
`Audit/fix: <surface>. Check authentication, authorization, ownership, data leakage, and regression.`

Verify:
`Verify: <recent change>. Use the impact map and targeted checks first; expand only when risk/dependencies require it.`

Do not paste source files into prompts when the agent can inspect them.
