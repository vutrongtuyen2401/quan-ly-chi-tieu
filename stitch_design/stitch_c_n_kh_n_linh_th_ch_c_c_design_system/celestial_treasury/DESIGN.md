## Brand & Style

This design system defines an intelligent wealth management interface that fuses 80% modern enterprise fintech rigor with 15% subtle Xianxia cultivation mysticism and a 5% companion spirit overlay. 

The aesthetic is tailored for modern Vietnamese investors, digital asset stewards, and personal financial cultivators who demand uncompromising data density, instant analytical clarity, and a differentiated atmospheric depth. The interface evokes a sense of tranquil sovereignty, spiritual discipline, and mathematical precision: night-sky slate surfaces, tempered nephrite jade currents, and controlled celestial talisman accents.

The design movement combines **Contemporary Enterprise Dark SaaS** with **Subtle Mystical Glassmorphism**:
- Structural layouts, grids, inputs, and tabular ledgers remain strictly utilitarian, fast, and accessible.
- Xianxia elements operate purely as spatial atmosphere, semantic indicators, and elevated focus states (jade spiritual energy, talismanic gold warnings, astral purple tier indicators), never obstructing utility or legibility.
- Fantasy components never use archaic calligraphy for functional numbers or labels; all critical financial metrics are set in high-contrast neutral typefaces with tabular figures.

## Colors

The color palette is built on deep cosmic darkness, balanced by jade spiritual resonance and talismanic gold:

- **Primary Core (Spiritual Jade - `#2B8A82`)**: Represents balance, cultivated growth, active selection states, key positive metrics, and active boundary glow.
- **Secondary Atmospheric (Celestial Midnight - `#1E1B4B`)**: Used for background radials, high-level cultivation modules, and spirit AI contextual glows.
- **Tertiary Accent (Talisman Gold - `#E8C874`)**: Reserved strictly for high-tier asset thresholds, pending seals, actionable warnings, and attention-critical alerts.
- **Neutral Ground (Void Slate - `#0F172A`)**: The structural foundation. Canvas backgrounds sit at `#090D16` to `#0F172A`, with layered container panels at `rgba(15, 23, 42, 0.75)`.

### Functional Tier Tokens
- **Celestial Indigo (`#7C3AED`, `#6D28D9`)**: Denotes automated algorithmic vaults and AI spiritual processing.
- **Gain / Upward Stream (`#10B981`)**: Financial yield, confirmed deposits, positive cash flow.
- **Loss / Tribulation (`#EF4444`)**: Capital outflow, risk infractions, stop-loss notifications.
- **Text Layers**:
  - `text-primary`: `#F8FAFC` (100% legibility on dark surfaces).
  - `text-secondary`: `#CBD5E1` (metadata, column headers, secondary figures).
  - `text-muted`: `#94A3B8` (placeholders, timestamps, micro-labels).
- **Border Tints**:
  - Default structural: `rgba(255, 255, 255, 0.08)`
  - Active jade aura: `rgba(43, 138, 130, 0.25)`
  - Celestial focus: `rgba(124, 58, 237, 0.35)`

## Typography

Typography prioritizes financial clarity, high optical contrast, and data density. Inter is utilized across all tiers, strictly enforcing `font-feature-settings: "tnum" on, "cv05" on, "cv11" on` for tabular, monospaced numerical rendering.

### Financial & Currency Rules
- Currency amounts must strictly follow standard Vietnamese Dong syntax: grouped with periods, accompanied by a non-breaking space and the currency sign `₫` (e.g., `1.500.000 ₫`, `24.850.200 ₫`).
- Financial metrics never drop below 12px (`body-sm`) to ensure accessibility across compact dashboard matrices.
- Uppercase styling is permitted only on `label-sm` when designating asset classes, ledger headers, or spiritual companion operational states (e.g., `PLANNING`, `CONFIRMING`).

## Layout & Spacing

The layout is engineered around an 8-point base rhythm grid optimized for financial analytical dashboards.

- **Desktop (>= 1280px)**: 12-column responsive fluid grid with `2rem` (`space-xl`) canvas margins and `1.5rem` (`gutter`) column spacing. Complex data ledgers span 8 or 12 columns; companion analytics widgets sit within 4-column sidebars.
- **Tablet (768px - 1279px)**: 8-column layout with `1.5rem` canvas margins and `1rem` gutters. Auxiliary spiritual metrics stack below primary balances.
- **Mobile (< 768px)**: 4-column fluid layout with `1rem` margins and `0.75rem` gutters. Tables shift to card summaries with sticky horizontal action strips.

All paddings, gap increments, and content relationships must align with tokenized distances:
- Tight inline groupings (tags, talisman icons, micro figures): `space-xs` (4px) or `space-sm` (8px).
- Input field vertical padding and compact cell height: `space-sm` (8px) to `space-md` (16px).
- Card body paddings: `space-lg` (24px) on desktop, `space-md` (16px) on mobile viewports.

## Elevation & Depth

Visual hierarchy uses translucent slate planes, blurred atmospheric backdrops, and delicate luminescent jade borders, avoiding heavy dropped mud shadows.

### Surface Tiers
- **Tier 0 (Abyssal Base)**: Solid canvas fill `#090D16` overlaid with a faint radial gradient centered at the top right: `radial-gradient(ellipse at 80% 0%, rgba(30, 27, 75, 0.45) 0%, transparent 70%)`.
- **Tier 1 (Substratum Panels)**: Financial cards and data tables sit on `rgba(15, 23, 42, 0.75)` with `backdrop-filter: blur(16px)` and a 1px solid stroke of `rgba(255, 255, 255, 0.08)`.
- **Tier 2 (Floating Portals / Dropdowns)**: Elevated modals, menus, and flyout palettes sit on `rgba(15, 23, 42, 0.92)` with `backdrop-filter: blur(24px)`, a 1px border of `rgba(43, 138, 130, 0.25)`, and shadow `0 12px 32px -4px rgba(0, 0, 0, 0.5)`.
- **Tier 3 (Active Spiritual Resonance)**: Hovered or selected cards introduce an inner diffused luminescence: `box-shadow: inset 0 1px 1px 0 rgba(255, 255, 255, 0.1), 0 0 20px -4px rgba(43, 138, 130, 0.2)`.

## Shapes

The design uses balanced, modern geometric curvature:
- **Default Inputs, Tags, and Table Rows**: `0.5rem` (8px) radius maintains dense spatial efficiency.
- **Card Containers and Modals (`rounded-lg`)**: `1rem` (16px) radius creates a soft boundary between data sectors.
- **Badges and Status Orbs (`rounded-xl` / Full)**: Pills (`9999px`) are designated exclusively for companion status indicators, talisman state tags, and action chips.
- Sharp geometry is strictly disallowed to ensure tactile affinity with jade talismans, while overly bubbly radii are avoided to preserve SaaS credibility.

## Components

### Buttons
- **Primary (Jade Essence)**: Solid background `#2B8A82`, text `#F8FAFC`, subtle top-edge highlight `1px solid rgba(255, 255, 255, 0.2)`. On hover: `#23736C` with `box-shadow: 0 0 16px rgba(43, 138, 130, 0.4)`.
- **Secondary (Astral Slate)**: Translucent fill `rgba(30, 27, 75, 0.5)`, border `1px solid rgba(255, 255, 255, 0.12)`, text `#F8FAFC`. On hover: border-color `rgba(43, 138, 130, 0.4)`, background `rgba(43, 138, 130, 0.1)`.
- **Talisman Alert Button**: Border `1px solid #E8C874`, fill `rgba(232, 200, 116, 0.08)`, text `#E8C874`.

### Input Fields & Controls
- **Fields**: Height `40px`, background `rgba(15, 23, 42, 0.6)`, border `1px solid rgba(255, 255, 255, 0.12)`, radius `8px`. Typography: `body-md` in `#F8FAFC`. Focus state: border `1px solid #2B8A82`, glow `0 0 0 2px rgba(43, 138, 130, 0.2)`.
- **Checkboxes & Radios**: Custom square/circle 18px indicators with `1px solid rgba(255, 255, 255, 0.2)`. Checked state: background `#2B8A82` with an inner white glyph.

### Cards & Data Tables
- **Cards**: Structural panels with padding `space-lg`, corner radius `16px`, background `rgba(15, 23, 42, 0.75)`, border `1px solid rgba(255, 255, 255, 0.08)`.
- **Ledgers & Data Tables**: Header row typography `label-sm` with text `#94A3B8` and uppercase tracking. Row height `48px`, border-bottom `1px solid rgba(255, 255, 255, 0.04)`. Numerical figures right-aligned with `currency-table` styling.

The companion utilizes a refined rune-ring aura surrounding a minimalist vector chibi spirit orb:
- **IDLE**: Soft breathing jade aura (`#2B8A82` pulse, opacity `0.4`), static subtle rune glyph.
- **THINKING**: Celestial Indigo rotation (`#7C3AED`), rotating inner orbital ring, calm constant glow.
- **PLANNING**: Deep Indigo and Jade dual-orbit gradient sweep, dotted trajectory paths.
- **CONFIRMING**: Talisman Gold ring (`#E8C874` glow), pulsing boundary requiring user action seal.
- **EXECUTING**: Rapid spinning astral ring, jade streaming trails, disabled backdrop dismissals.
- **SUCCESS**: Sharp single flare of Jade green (`#10B981`) settling into a tranquil jade ring.
- **ERROR**: Tribulation red boundary (`#EF4444`) with sharp geometric talisman fracture indicator.
