# Project Core Rules
- Read `AI_PROJECT_CONTEXT.md`, `ROADMAP.md`, `AGENTS.md`, and applicable rules/skills before coding.
- Search usages before changing shared functions, API contracts, database models, or response shapes.
- Make the smallest coherent change. Do not perform unrelated refactors.
- Never expose secrets or introduce fake financial data.
- Never disable validation/auth/authorization or weaken tests to make checks pass.
- Code is not complete until the applicable verification gate passes.
